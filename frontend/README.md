# TrendWeaver Engine - Frontend

Next.js (App Router) application serving as a dummy blog with SEO meta tags intentionally left blank for server-side injection.

## Features

- App Router architecture
- TailwindCSS styling
- Server-side rendering ready
- Placeholder SEO meta tags for injection

## Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Architecture

This frontend intentionally leaves SEO meta tags blank. The AI agent backend will:
1. Analyze content trends
2. Generate optimized SEO metadata
3. Inject meta tags server-side before page delivery

## Development

- Main page: `src/app/page.tsx`
- Layout: `src/app/layout.tsx`
- Styles: `src/app/globals.css`
